# ساخت APK بدون نیاز به Android Studio (با GitHub Actions)

این پروژه یه ورک‌فلوی GitHub Actions داره (`.github/workflows/build-apk.yml`) که APK رو خودکار توی سرورهای گیت‌هاب می‌سازه. شما فقط باید کد رو توی یه ریپازیتوری گیت‌هاب قرار بدید — نه Android Studio لازمه نه SDK نصب کردن.

## مراحل (یک‌بار برای همیشه)

### ۱- ساخت ریپازیتوری در گیت‌هاب
- اگه اکانت گیت‌هاب ندارید، توی github.com یکی بسازید (رایگان).
- یه ریپازیتوری جدید بسازید (مثلاً به اسم boxing-app)، می‌تونه Private باشه.

### ۲- آپلود فایل‌های این پروژه
ساده‌ترین راه بدون نیاز به خط فرمان:
- توی صفحه‌ی ریپازیتوری، روی Add file → Upload files بزنید.
- کل محتوای پوشه‌ی boxing-apk (که از من گرفتید) رو بکشید و رها کنید — شامل پوشه‌ی .github هم می‌شه (این پوشه مخفیه، مطمئن بشید توی آپلود جا نمونده).
- Commit کنید (دکمه‌ی سبز پایین صفحه).

نکته: اگه فایل مخفی .github رو مرورگرتون توی درگ-اند-دراپ نشون نداد، از ابزار GitHub Desktop (رابط گرافیکی ساده، بدون خط فرمان) کل پوشه رو push کنید.

### ۳- اجرای ساخت APK
- بعد از commit، وارد تب Actions بالای صفحه‌ی ریپازیتوری بشید.
- یه اجرای جدید به اسم "Build Android APK" می‌بینید که در حال اجراست (چند دقیقه طول می‌کشه).
- وقتی تمام شد (علامت ✅ سبز)، روی همون اجرا کلیک کنید.
- پایین صفحه بخش Artifacts رو ببینید — فایل boxing-app-debug-apk همونجاست، دانلودش کنید (یه zip داره که APK داخلشه).

### ۴- نصب روی گوشی
فایل APK رو به گوشی اندرویدی منتقل کنید و نصبش کنید (شاید لازم باشه گزینه‌ی "نصب از منابع ناشناس" رو فعال کنید).

## بعداً که تغییری دادید
هر بار که فایل‌ها رو توی گیت‌هاب آپدیت/آپلود کنید (commit جدید روی شاخه‌ی main)، ورک‌فلو خودکار دوباره اجرا می‌شه و APK جدید می‌سازه.

## نکات مهم قبل از انتشار واقعی

1. **آدرس بک‌اند**: توی www/app.jsx این خط رو با آدرس سرور واقعی‌تون عوض کنید:
   const API_BASE_URL = "https://YOUR_SERVER_URL";
   تا این مقدار عوض نشه، اپ توی حالت DEMO اجرا می‌شه.

2. **این یه APK دیباگه (debug)**: برای نسخه‌ی نهایی قابل انتشار در Google Play باید APK رو امضا (sign) کنید. اگه لازم شد بگید تا مرحله‌ی امضای خودکار رو هم اضافه کنم.

3. **آیکون اپ**: فعلاً آیکون پیش‌فرض Capacitor رو داره.

4. **اجرای کاملاً آفلاین**: الان React/Tailwind/Babel از CDN لود می‌شن، یعنی گوشی موقع اجرای اپ به اینترنت نیاز داره. اگه می‌خواید بدون اینترنت کار کنه بگید تا یه نسخه‌ی build-شده آماده کنم.
